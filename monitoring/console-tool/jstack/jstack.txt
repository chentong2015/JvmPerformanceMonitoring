jstack [-l][-e] PID  打印进程中线程信息/自动分析死锁
-l  long listing.
    Prints additional information about locks
-e  extended listing.
    Prints additional information about threads
    Prints the stack traces of all java threads for a given process or core dump.
    Each thread consists of a header and a stack trace
